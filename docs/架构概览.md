# 架构概览（C++ 现状基线）

> 本文描述当前 `master` 上 C++17/Win32 版本的实际结构，作为后续玄铁重写的对照基线。仅基于源码现状记录，不含改造方案。

## 1. 定位与技术栈

KeyBonk（发声键盘）是一款 Windows 桌面音效软件：通过低级全局钩子监听键盘/鼠标，按下时按虚拟键值（VK）播放对应 wav，并以置顶透明分层窗口展示背景图。

- 语言/标准：C++17，宽字符（Unicode）构建
- GUI：原生 Win32 API + GDI+（分层窗口 `UpdateLayeredWindow`）
- 音频：第三方 `yumo audio-player`（预加载 + 混合播放），二进制 `.a` 不入库，构建期下载
- 构建：MSYS2/MinGW GNU Make（64/32 位），Inno Setup 打包
- 目标平台：仅 Windows（x64/x86）

## 3. 启动流程（`wWinMain`）

1. 解析 `./log.txt` 绝对路径；单实例检测：`FindWindow("KeyBonk主窗口")` 命中则发自定义消息激活已有实例并退出。
2. 写启动时间日志；读 `./config.ini`：`[record]` 的 `win-x/win-y/mute/mute-m`，`[settings]` 的 `lib`（音频库目录，默认 `.\bin\default`）。
3. `CoInitializeEx` 初始化 COM（为未来功能预留）；注册主窗口类并 `CreateWindowExW`（`WS_EX_LAYERED|WS_EX_TOPMOST|WS_EX_TOOLWINDOW`，`WS_POPUP`）。
4. `GdiplusStartup` 初始化 GDI+；构造 `background` 加载默认背景图，按异常类型（文件未找到/尺寸非法/未知）弹窗报错。
5. `detach` 后台线程执行音频预加载（见下）。
6. 安装 `WH_KEYBOARD_LL`、`WH_MOUSE_LL` 低级钩子，失败弹窗并退出。
7. 进入 `GetMessage` 消息循环。

## 4. 核心数据流：触发 → 发声

**预加载（后台线程 `preloadAudio`）**

遍历音频库目录（递归），仅处理 `.wav`：文件名（去扩展名）须为纯数字且落在 0–255（即合法 VK 范围），调用 `yumo::preloadAudio` 得到 preloadId，加锁写入 `global.audioList[vkCode] = preloadId`；全部完成后置 `audioPreloadReady = true`。

**播放路径**

```
键盘 WM_KEYDOWN (未 Mute) ──► PlayAudioFile(vkCode)
鼠标 左/右键 (未 MuteMouse) ─► 随机取 {74,77,78,84} ─► PlayAudioFile(keyCode)
                                        │
                            audioPreloadReady? 是
                                        ▼
                    audioList 查 vkCode → preloadId 命中?
                                        ▼
                          yumo::addAudio(preloadId) 入队混合播放
```

- `PlayAudioFile` 在预加载未就绪时直接忽略（竞态安全，不加锁）。
- yumo 负责混音与播放生命周期，本进程只提交预加载句柄。

## 5. 窗口、托盘与菜单交互

- 主窗口为无边框分层窗口：右键弹出菜单，托盘右键同菜单；托盘左键双击恢复显示。
- 菜单项：窗口穿透（切换 `WS_EX_TRANSPARENT` 并调低整体透明度）、键盘静音、鼠标静音、最小化（隐藏到托盘）、设置、关于、退出。
- `WM_NCHITTEST` 把客户区命中改为 `HTCAPTION`，实现按住拖动。
- `WM_CLOSE` 确认后把窗口位置写入 `config.ini`；`WM_DESTROY` 删除托盘、写回静音状态、`PostQuitMessage`。
- 关于/设置窗口均为单实例（已存在则激活前置，不重复创建）。

## 6. 配置与日志

- `config.ini`（exe 同级）两节：
  - `[record]`：`win-x`、`win-y`（退出时记录的位置）、`mute`、`mute-m`（键盘/鼠标静音）。
  - `[settings]`：`lib`，音频库目录路径。
- `log.txt`：UTF-8 追加写，初始化与各失败分支记录，打开失败静默跳过。

## 7. 第三方与系统依赖

- `yumo audio-player`：头文件在 `libs/audio-player/`，链接用 `.a` 由 `download_audio_lib.ps1` 从 `keybonk-org/audio-player` 最新 Release 按架构（x64/x86）下载、校验解压。
- 系统导入库（见 Makefile `LDLIBS`）：`user32 gdi32 ole32 gdiplus winmm msacm32 comdlg32`。

## 8. 现状备注（客观记录，未改动）

- 鼠标音效列表 `{74,77,78,84}` 在 `mouse_hook.cpp` 内硬编码，未走音频库扫描。
- 设置窗口仅一个静态标签，未接音频库选择逻辑。
- `background::resetBackground(keyCode,isMouse)` 支持按 `keyboard|mouse/<vk>.png` 切图，但主流程未调用（`main.cpp` 留有 TODO）。
- `others.cpp` 的 `safeRelease` 当前无调用方。
- `include/yumo_except.hpp` 与 `libs/audio-player/yumo_except.hpp` 是两份不同内容，分属项目与库。
- 最新 tag `V1.4.1.0` 指向当前 HEAD，但源码 `appVersion` 与 `installer.iss` 版本字符串仍为 `1.4.0.0`，tag 与版本号未同步。
- `CoInitializeEx` 当前为预留初始化，暂无实际 COM 使用。
