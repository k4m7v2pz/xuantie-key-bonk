## 构建期与运行期布局（不在 Git 内）

- `Makefile` 编译产物输出到 `build/<arch>/`；链接所需的 audio-player `.a` 由 `download_audio_lib.ps1` 下载到 `build/<arch>/libs/`。
- 运行期默认音频库目录为 `bin/default/`：`audios/` 放按键 wav，`background.png` 放 `imgs/`，`icon-org.png` 放库根；该布局由 `Makefile`（开发态复制）与 `installer.iss`（安装包）共同保证。
